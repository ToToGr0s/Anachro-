Sur les 7 derniers jours. « Cochées » = tâches passées à Fait.

Ces liens s'affichent en boutons en haut du planning, pour tout le monde (spectateurs compris). GDD, PDF, Google Doc, Figma, Drive… n'importe quelle adresse https://. Pour un PDF : mets-le sur Google Drive (partage « Tous les utilisateurs disposant du lien ») et colle le lien ici.

Le bot poste dans un salon Discord : récap le lundi à 8h45 et bilan le vendredi à 16h30 (semaines studio), alertes J-3 / J-1 avant les jalons, et alerte immédiate quand une tâche passe en « Bloqué ».

Identifiant Discord : dans Discord, Paramètres → Avancés → active le Mode développeur, puis clic droit sur la personne → « Copier l'identifiant de l'utilisateur ». Sans identifiant, le prénom est écrit sans mention.

Chaque personne se connecte avec son nom + son code. Génère un code et envoie-le-lui en privé : il ne sera plus affiché ensuite.
